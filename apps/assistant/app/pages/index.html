Written by real outages.

Each of these broke this platform first. Now they're runbook entries.

GitHub Actions

Not authorized to perform sts:AssumeRoleWithWebIdentity

Cause. The repo uses immutable OIDC subject claims, so the trust policy never matched.

Fix. Write the subject in its immutable form and re-apply the role.

Terraform

the cached package does not match any of the checksums recorded in the dependency lock file

Cause. The lock file only had hashes for the laptop's platform. CI runs Linux.

Fix. Lock both platforms and commit the file.

Logging

Back-off restarting failed container filebeat

Cause. Filebeat 9 dropped the container input. The old config started nothing.

Fix. Switch to a filestream input with the container and ndjson parsers.
